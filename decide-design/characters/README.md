# 決斷連 · 8-bit 角色交付

三位角色 × 五表情，15 張原尺寸 PNG 與 15 張無損 WebP。`public/officers/` 可直接合併至專案的同名目錄。

本次採用簡報允許的既有 sprite 精修路線：在 48×48 格線修改 `design/sprites.mjs`，從固定骨架產出所有表情。沒有 AI 大圖生成或重採樣失真。`enlarged/` 是 20 倍最近鄰預覽，正式資產請用 48×48 版本。

## 已確認的取捨

- 老郭增加 NES 色表中的 `#F83800` 紅哨繩，經使用者確認；和黑色制服陰影共色後，仍只有 8 個不同色。
- 描邊採各角色最終色表 `#000000`，不沿用總綱舊的 `#16180F`。阿良頭髮也併入黑色。
- 阿良歪帽往角色右側（觀看者左側），雙瞳高光固定左上；汗滴固定 2×4 色塊，praise 才移除。
- soft 的眼神同向平移；老郭用鏡片反光微移表示，墨鏡框不動。Mood 型別仍留給原工程端接入。
- 值星帶由角色右肩到左腰。前視圖是畫面左上往右下。名牌在觀看者左側，避開值星帶遮擋。
- 金環帽徽、汗滴與表情短線都有深色像素描邊。

## 驗證結果

15 張皆 48×48、alpha 僅 0／255、每張 7–8 色，均在該角色色表內。三人共用 #FCA044 膚色。PNG／無損 WebP 可見像素相同。換表情時帽子與制服不漂移；變更限制在眉嘴、明訂的眼神例外及表情符號。獨立 checker 已檢查原寸／放大剪影與表情分寸。

NES 原機輸出複合視訊，沒有唯一 RGB 色表。本案精確採用 repo `hwpalette.mjs` 的 NES 色表；這是手機素材，不宣稱可直接載入 NES ROM 而不做圖塊與子調色盤分配。

**仍待真人驗證：** 五名當過兵的人、48px、2 秒辨識，至少三人回答台灣。請用 `blind-test.html` 收集原始回答；本次沒有代填或模擬人類通過結果。

## 重建

需要 Node.js、Python 3 與 Pillow。在專案根目錄執行：

```sh
python3 design/8bit/export.py /path/to/output
```

會重建15張 PNG／WebP、總覽、剪影與色表紀錄，並更新專案 public/officers。原 normalize 工具也修正成最終色表並保留透明背景上的黑色輪廓，但本次原生48px素材不需要經過該工具。
