## 0. 先說三個前提問題（這三題不先答，下面的建議會失準）

**(a) 你現在的風格其實已經是美式了。** CHARACTER-BRIEF §0 寫的是「flat vector、thick outline、Duolingo / Headspace / Carrot Weather 等級」——這就是美式吉祥物設計語言。所以「改成美式卡通」到底是要移動哪一軸？我猜是其中之一，風險完全不同：

- 想要**更大的表情幅度與動畫感**（Gravity Falls / Kim Possible 那種）→ 風險低，多半可以做。
- 想要**更強的造型誇張**（頭身比、下巴、肌肉）→ 風險高，這是吃掉在地性的主要通道。
- 想要**更 rubber-hose / 復古美卡**（Cuphead、Popeye）→ 風險最高，因為那是**美國 1930 年代**的年代感，會和你要的**台灣 1990 年代**正面對撞，兩個年代互相消滅，最後誰都不是。

**(b) 「美式卡通」不是一種風格，是至少六種。** 對這個案子的安全性由高到低大致是：UPA／中世紀平面感 ≈ 現代圖像小說系（Gravity Falls、Over the Garden Wall）> Hanna-Barbera 限動系 > CalArts 豆豆嘴系 > rubber hose 系 >> **超級英雄／G.I. Joe 系（絕對不要碰，那本身就是軍國主義的視覺語彙）**。請先鎖定子方言再發包，否則你會拿到六種東西的平均值。

**(c) 台灣使用者的卡通識讀是日系的，不是美系的。** 你的目標客群（當過兵、記得軍教片的 30–50 歲台灣男性）從小看的是日本漫畫與台灣本土插畫 IP。純美式語彙對他們可能**比日系更陌生**。你的 brief 裡 阿良 的汗滴（#5DADE2）就是日式漫符——那顆汗滴對台灣人的可讀性，其實高於任何美式等效物。所以：如果改風的理由是「國際化／上 App Store 精選」，合理；如果理由是「台灣人會更喜歡」，這個假設需要驗證，我不認為它成立。

## 1. 會失去什麼（具體到視覺元素）

美式卡通的造型邏輯有三條內建規則，每一條都會吃掉一個在地標記：**權威從下巴與眉骨來、身體從肌肉來、服裝貼合身體**。逐項：

| 一旦被吃掉 | 台灣人就認不出的原因 |
|---|---|
| **臉的骨架** | 美卡把權威放在下顎：方下巴、下巴比顴骨寬、眉骨壓出眼窩陰影、鼻樑從眉間就起高。換上去之後就是「一個穿草綠服的白人」。台灣臉的結構是**顴骨最寬、鼻樑起點低而短、下巴不外突、眼在較平的面上**。這一項壞掉，其他做對都救不回來。 |
| **髮型** | 美式軍人反射動作是 high-and-tight（兩側剃光＋頂上平台）或 flattop，那是**美國海軍陸戰隊標記**。台灣 90 年代義務役是**三分頭／五分頭**——長度均勻、有真實髮際線、頭頂微圓，不是平台。這是最快被換掉、也最少人注意到被換掉的一項。 |
| **軍服的布感** | 草綠服是**寬鬆棉布、會皺、領子撐不太起來、有內務燙出來的燙線**。美卡會把制服畫成貼合身體的色塊、領子筆挺、零皺褶。失去「鬆垮＋燙線」＝失去台灣兵。 |
| **素色 vs 迷彩** | 美卡的「軍人」預設是迷彩。一旦出現任何迷彩紋，年代直接從 1990 跳到現代，題材從軍教片跳到現代戰爭片。**草綠服必須是純色。** |
| **帽子** | 船形帽是台美共用品項（美軍 garrison cap 同型），所以它**本身不具識別力**，識別力全在帽徽。而美式繪師的 drill sergeant 反射是**campaign hat（寬圓邊的教官帽）**——一旦飄過去，角色瞬間變成 Full Metal Jacket。 |
| **帽徽** | 見下節，這是你現在 brief 裡最嚴重的一個錯。 |
| **值星帶** | 美卡會把它理解成 sash／baldric：寬度不對、角度不對、加上扣具、甚至變成選美彩帶。 |
| **名牌** | 台灣是**右胸白色硬質塑膠牌＋黑色繁體中文**。美式預設是布質 name tape（黑底白繡字）。材質讀感一換就假。 |
| **膚色與曬痕** | 台灣義務役的臉是**帽子曬痕**（額頭一條白、以下黑）＋短袖曬痕。美卡的單一膚色平塗會把這個刪掉。這是成本極低、識別力極高的一項。 |
| **體型** | 美卡的士官＝倒三角、三角肌、細腰、頸比頭寬。台灣 90 年代的班長是**精瘦**或**中年小肚子**，制服鬆垮罩在上面。給他 V 字身材就變成 G.I. Joe。 |
| **年代質感** | 美式向量卡通是「現在」的，圖面上沒有任何東西說 1990。而你整個產品的笑點就建立在年代感上。這一項失去＝產品的核心失去。 |
| **繁體中文本身** | 美式吉祥物設計慣例是「無文字」。但中文字是這個題材最便宜、最強的文化載體（名牌、值星、部隊番號、莒光園地標語）。textless 化＝自廢武功。 |
| **「情義」的表情層** | **這是最大的一項，而且跟服裝無關。** 軍教片班長的核心情緒節拍是「刀子嘴豆腐心」——罵完之後**別過頭、不看你、嘴角鬆一下**。美卡的表情訓練是「每一格都要完全可讀、幅度拉滿」，它沒有「藏」這個動作。你現在四個 mood（idle / bark / praise / punish）全是高幅度，一旦再用美式放大，**只剩「兇」，情義會整個消失**，角色從班長變成霸凌者。 |

另外：**bust（胸上）構圖本身已經砍掉了姿態**。立正、稍息、插腰、雙手背後——這些是極強的在地標記，現在一個都用不到。

## 2. 不可讓渡清單（畫風全換也必須留）

依識別力排序。前五項任一條壞掉，這個角色就不是台灣班長。

1. **帽徽＝十二道光芒的青天白日系裝置，不是五角星。**
   你 brief §0 寫的是「金色五角星在圓框內」。**這是錯的，而且錯得敏感。** 中華民國國徽是青天白日（十二道光芒、藍底白日）；**金／紅色五角星是解放軍與蘇聯系統的符號**。一個台灣軍教片題材的 app 掛著五角星，在台灣會被截圖轉發。
   建議：做一個**虛構部隊徽**——取十二道光芒的節奏感（放射短芒＋圓框），但明確不是國徽本體。這同時也避開「在喜劇角色上使用真實國徽」可能的爭議（刑法有侮辱國旗國徽的條文，構成要件我不確定、也不是法律意見，但用虛構徽記可以讓這題根本不存在）。承載：**國別**。

2. **值星帶（紅底＋細金邊，斜掛）。**
   全套裡最不可能被誤讀成美軍的一件，它是台灣軍隊制度的具體物。**但方向我不確定**：你 brief 寫「左肩斜到右腰」，我沒有把握是左肩還右肩，這是二元的、當過兵的人一秒就看出來，而且生成式模型**每一張都會隨機翻**。請先找一張確實的參考照定死，然後**逐張驗收方向**，不要相信 prompt。承載：**職務＋制度**。

3. **草綠服的結構：純色、立領／開領、兩個胸袋蓋、燙線、寬鬆。**
   承載：**年代＋國別**。四者缺一都會滑走，其中「純色」與「寬鬆」最容易被美卡吃掉。

4. **白色硬質名牌＋繁體中文姓名。**
   承載：**語言＋國別**。成本最低、效益最高的一項，務必在 96px 還看得出「那是一塊白牌子上有中文」。

5. **三分頭（非 high-and-tight）＋帽子曬痕。**
   承載：**身體的在地性**。這是唯一一項在「脫掉制服之後」還能撐住台灣感的元素——見第 4 節的「去制服測試」。

6. **士官階級的差異（三人不同）。**
   阿良／黑面／老郭 的階級應該看得出不同（下士 → 中士或上士 → 士官長）。ROC 士官領章的確切形制我不確定，需查證；但**「三人階級不同且可辨」**這件事是免費的真實度，美式簡化一定會把它抹平成同一件衣服。

7. **內衣白領從草綠服領口露出一截。**
   極在地、極便宜。承載：**生活感**——這不是軍隊符號，是台灣兵的日常。

8. **臉的構造規則：權威來自眉毛與法令紋，不來自下巴。**
   把這句直接寫進發包文件。你 brief §0 已經有「eyebrows and mouth carry the emotion」，很好，**再加一句「chin and jaw carry nothing」**。

9. **繁體中文字體＋90 年代印刷質感**（套色不準、褪色、油印藍、粗黑體與美工字）。承載：**年代**。

10. **一個非最大幅度的表情。**
    建議新增第五個 mood：`soft` 或 `背影`——罰則結束後用，眼神別開、嘴平、或直接 3/4 背面。這一張圖是「情義」的唯一載體。四個滿幅度的表情撐不起這個角色。

## 3. 可安全借用 vs 會造成文化錯置

### 可以安全借用（這些是「動詞」，沒有國籍）

- **骨架與可讀性原則**：剪影優先、大小形狀層級、線寬系統、負空間。純技術。
- **誇張法的時間向度**：squash & stretch、anticipation（吼之前先吸一口／帽子先抖）、smear、極端 hold pose、take（誇張反應）。這些是**節奏**，不是**解剖**。
- **表情幅度**：嘴型放大、眉毛不對稱、瞳孔縮放、牙與舌可見。條件是解剖地標不動、且三人的眼型必須有差異（見下）。
- **喜劇節拍**：「吼 → 切 → 面無表情」的二拍結構、停頓後爆發。台港喜劇的節奏本來就與此相容，軍教片本身也這樣演。
- **色彩處理**：平塗、限定色盤、用顏色編碼狀態／角色。
- **道具的卡通化**：哨子吹到變形、值星帶被吼的氣浪掀起、帽子彈起來。這些是安全的，而且很有效——**把誇張放在道具上，不要放在身體上**，是這個案子最重要的一條操作原則。

### 借了會錯置（逐項附替代方案）

| 美式反射 | 為什麼錯 | 改成 |
|---|---|---|
| high-and-tight / flattop | 美國海軍陸戰隊標記 | 三分頭，均勻長度，有真實髮際線 |
| 燈籠下巴、裂下巴、下巴比顴骨寬 | 西方臉的權威語法 | 顴骨最寬，下巴窄而略圓 |
| 深陷眼窩＋眉骨陰影（Bruce Timm 眼） | 同上 | 眉毛是浮在眼睛上方的圖形筆畫，不挖眼窩 |
| 高鼻樑從眉間起、鉤鼻／球形鼻頭＋人中明顯 | 同上 | 鼻樑起點低、短、鼻基寬，人中淺 |
| V 字身材、三角肌、頸比頭寬 | G.I. Joe 化 = 軍國主義化 | 頸比頭窄；肩線的方是**衣服的方**，不是肌肉的方 |
| 貼身制服、緊捲袖露二頭肌 | 美式作戰服讀感 | 寬鬆＋燙線；若要捲袖，用寬幅反折到肘上的台式捲法 |
| 狗牌掛在衣服外面 | 美國電影圖像 | 收進衣內，或不畫 |
| 飛行員墨鏡＋哨子掛胸前 | **這正是美式 drill sergeant 的全套：墨鏡＋方下巴＋哨子＝ R. Lee Ermey。你的老郭現在就是這個組合。** 在平面向量風格下勉強撐得住，一換美卡會直接吸過去 | 老郭改成**老花眼鏡滑到鼻尖**＋眼袋＋曬斑＋眉間白毛；哨子保留但**哨繩穿過肩袢、哨子收進口袋**（不是教練式垂在胸前）。再加一個鋼杯或摺起來的值星簿，比墨鏡在地十倍 |
| campaign hat（寬圓邊教官帽） | 美軍教官帽 | 船形帽，鎖死 |
| 任何迷彩 | 年代與國別雙錯 | 純色草綠 |
| 布質 name tape、美式肩章排列 | 美軍編排 | 右胸白色硬牌＋中文 |
| 掌心向上、食指勾動的「過來」手勢 | 西方手勢；台灣是**掌心向下、整手向內撥** | 掌心向下撥 |
| 聳肩攤手 | 純西方 | 抱胸、插腰、雙手背後 |
| 敬禮定格 | 台美敬禮形制不同（細節我不確定，需查照片）；而且**敬禮姿勢本身是所有姿勢裡最接近宣傳海報的一個** | 建議乾脆不畫敬禮 |
| 豆豆嘴、舌頭歪出來、單顆缺牙 | 美式甜化，會消滅兇度與年代感 | 不用 |

**關於眼型的特別警告**：你 brief 給黑面「一字平眼、細長」，bark 時三人都「瞇」。在**全員都是簡化形狀**的平面風格下這沒問題。但美式卡通的慣例是圓大眼＝主角、細線眼＝配角，一旦只有東亞角色是細線眼，就會落進「瞇瞇眼」的種族刻板檔案裡。安全規則：**三人眼型必須明顯不同，且每個角色至少有一個 mood 是眼睛完全睜開的。** 你的 punish 設定寫「圓瞪」，正好滿足，務必保留，不要讓繪師在美式化時改掉。

## 4. 前例與可操作原則

只列我有把握的。

**有把握：**
- **《幸福路上》（2017，宋欣穎）**——台灣長片動畫，造型是簡化、圓潤、明顯受西方卡通影響的臉，但整部片極度在地（台語、眷村、國小升旗、時代事件、阿嬤）。它證明了**簡化的臉不會消滅台灣性**，只要環境、服裝、語言、器物把負載扛起來。這是你最該研究的一部。
- **《The Book of Life》／《El Tigre》（Jorge Gutiérrez）**——墨西哥裔創作者，用徹底的美式／百老匯卡通造型語言承載 lucha libre 與亡靈節。作法是：**角色結構交給美式，文化負載全押在紋樣、色彩、器物、輪廓剪影上**。
- **《Coco》（Pixar, 2017）**——美國工業流程 ＋ 極具體的墨西哥素材，公開的作法是長期在地顧問群 ＋「不准出現泛用化元素」的內規。
- **《Wolfwalkers》／《The Secret of Kells》（Cartoon Saloon）**——愛爾蘭題材，風格**是從在地視覺傳統（凱爾特泥金裝飾手抄本）長出來的**，不是把題材塞進外來風格。這是最高標。
- **《Hilda》**——北歐民俗題材、現代西方扁平卡通造型，在地性靠**民俗生物、服裝、環境**保住，不靠臉。
- **《Samurai Jack》（Genndy Tartakovsky）**——把臉抽象到幾乎沒有五官，卻靠**剪影與負空間**撐住文化讀感。技術示範。

**反面（同樣有把握，值得警惕）：**
- **《Avatar: The Last Airbender》**——常被當成正面例子，但它是**泛亞融合**：把中、日、韓、藏、因紐特揉成一個虛構文化。對你這個案子，這正是最該避免的失敗模式——變成「亞洲軍人」而不是「台灣兵」。

**歸納三條可操作原則：**

**原則一：風格從素材長出來，不是把素材塞進風格。**
不要從美式卡通參考圖開始。先去蒐 90 年代台灣的**部隊印刷品**——莒光日教材、精神標語、油印公文、部隊合照、軍中月曆——從那裡抽線寬、色偏、字體、印刷質感，**再**把美式的誇張與節奏疊上去。做出來的東西會是「用美式節奏演出來的台灣印刷品」，而不是「換皮的美國卡通」。

**原則二：文化負載放在三個不可壓縮層——服裝結構、器物、環境；臉可以自由簡化。**
定一條預算規則寫進發包文件：**要砍細節，永遠先砍臉，絕不砍裝備。** 帽徽、值星帶方向、名牌中文、燙線、曬痕、階級章——這六項在任何簡化程度下都必須保留。臉可以簡化到剩三個形狀，沒關係。

**原則三：建立一個「誰來驗收」的機制，而不是只有一張檢查表。**
你 §4 的檢查表寫得很好，但全部是自我檢查。加上外部驗收：**找 5 個真的當過兵的人，看 96px 縮圖、不給任何說明、2 秒內回答「這是哪一國、哪個年代的兵？」** 通過條件是 5/5 答「台灣」、至少 3/5 答得出 90 年代。這是唯一能抓到「看起來很好但其實是美國兵」的方法。

**另外四個我建議加進 §4 的測試：**
- **去制服測試**：把制服換成白 T 恤，臉還像不像台灣人？如果不像，代表文化負載全押在制服上，結構太脆——這是美式改風後最典型的失敗型態。
- **剪影測試**：全黑剪影，三人仍可辨，且仍不像美軍。
- **遮字測試**：把所有中文遮掉，還剩多少台灣？
- **惡意截圖測試**：見下節。

## 5. 軍事題材敏感度：要避開的具體畫法

這一節請當成硬性禁令，不是建議。台灣對軍中管教的集體記憶不是抽象的——**2013 年洪仲丘案**之後，體罰、操練、禁閉在台灣不是可以輕鬆入畫的題材。喜劇化的班長成立，前提是**他的權力永遠只作用在語言上，從不作用在身體上**。

### A. 會讀成「軍國主義符號」的畫法

1. **仰角英雄鏡位**——低角度、角色頂天、背光、觀者仰望。這是宣傳海報的文法。**固定用平視或略俯視**。
2. **頭後的放射狀光芒**。你 brief 的 praise 設定是「頭兩側各兩道金色小放射線」——這個尺度是安全的。**但一旦美式化把它擴成頭後的全圓放射光束，就是旭日旗**（在台灣、韓國、中國都讀成日本帝國主義）。硬規則：**短線、只在兩側、成對、絕不超過 4 道、絕不成圓、絕不紅白放射。**
3. **五角星**（見第 2 節第 1 條）。
4. **多人整齊列隊、同一姿勢的群像**。一個人是角色，一排一樣的人是集體符號。維持單人胸像。
5. **老鷹、月桂葉、飄揚旗幟、握拳、行進剪影、鐵絲網、槍**。你 brief 已寫「沒有槍」，很好，把這份禁令擴充成上面整串。
6. **莊嚴化的色彩處理**——飽和草綠＋高對比金＋銳利無瑕的印刷，是極權海報的配方。**解法是「舊」與「土」：褪色、套色不準、紙纖維、略髒的金。懷舊會殺死莊嚴。** 這同時解決了年代感問題，一石二鳥。

### B. 會讀成「霸凌者」而不是「嚴厲但有情義」的畫法

7. **笑著發怒**。憤怒＋咧嘴笑＝「他在享受」＝施虐。**punish 的嘴必須是吼，不能是笑弧。** 你 brief 寫「咧牙怒吼」，注意讓繪師分清「怒吼的張口」與「獰笑」——差別在**嘴角方向**（向下＝怒，向上＝虐）與**眼睛**（瞪＝怒，瞇笑＝虐）。
8. **針孔瞳孔＋全露眼白**。這組合在卡通裡是「失控／瘋狂」的符號，不是「嚴格」。
9. **貼臉構圖 / 破框**——角色的臉逼到畫面外、手指戳向觀者、口水噴出、近到看得見小舌。這是 Full Metal Jacket 的經典構圖，也是美式繪師畫 drill sergeant 的預設反射。**規則：角色永遠待在自己的框裡，攻擊性由文字承擔，不由身體承擔。**
10. **任何體罰器具或暗示**——藤條、棍棒、皮帶、抓領子、踩背、指地板（＝伏地挺身）、舉手作勢要打。全數禁止，無例外。
11. **罰則畫面的壓迫構圖**。你 DESIGN-BRIEF §3 說罰則倒數「沒有壓迫感」想加強——請注意加強的方向。**壓迫感要來自時鐘，不要來自身體**：班長應該**別過頭、抱胸、背對、等**，而不是站在你頭上放大。前者是「他在等你自己做到」，後者是「他在壓你」。這個分別就是整個產品的道德位置。
12. **用體型製造笑點**——胖菜鳥、矮呆兵。在台灣脈絡下這會連到真實的驗退／體位羞辱。**阿良的笑點必須來自他「兇不起來」（眉壓下去但眼睛還是圓的），不能來自他的身體。** 你 brief §2 那句設定寫得很好，請把它升級成禁令。
13. **只有細線眼的東亞角色群**（見第 3 節）。

### C. 驗收方法

**惡意截圖測試**：把 punish 那張圖單獨切出來，拿掉所有 app 脈絡，配上最惡意的一句話，放在推特的想像情境裡看。**如果它看起來像一張霸凌梗圖或一張軍國主義海報，就退回重畫。** 這是唯一能抓到公關風險的測試，因為在產品脈絡裡看每張圖都很合理，出事的永遠是脫離脈絡的那一張。

## 6. 針對你目前工作流程的一個具體警告

CHARACTER-BRIEF §3 是一條「貼 prompt 給 ChatGPT 生圖」的流程。在**美式卡通風格**這個條件下，這條流程有結構性問題：

生成模型看過的「美國 drill sergeant 卡通」比「中華民國草綠服」多幾個數量級。你在 prompt 裡寫「American cartoon style」，等於把權重又往那邊推一次。結果會是：模型持續給你 campaign hat、迷彩、美式肩章、五角星、西方臉，**而且因為它們畫得很好看，你會通過它們**。這是最危險的失敗模式——不是明顯的錯，是舒服的錯。

三個對策：

1. **裝備不要讓模型發明。** 提供真實的草綠服、船形帽、值星帶、名牌**參考照片**當 image reference，而不是只有文字描述。
2. **三張 idle 找台灣繪師畫。** 三個角色的基準圖（turnaround）人工完成並鎖定，生成只用來做表情變體（bark / praise / punish / soft）。成本增加有限，但它把文化判斷留在人手上。
3. **§4 檢查表加上「哪一國的兵」那一題，而且由當過兵的人答，不由你答。** 你太熟悉自己的設定，已經沒有辦法再用陌生的眼睛看它了。

---

**一句話的結論：** 這個改風可以做，但它必須是「用美式的**節奏與誇張**演出台灣的**服裝、器物與臉**」——借動詞，不借名詞。把誇張放在道具和時間上，把文化放在裝備和骨架上，把攻擊性全部留給文字。如果發包時說不清楚這條界線，你拿回來的會是三個穿草綠服的美國兵，而且他們會很好看，這就是為什麼你會通過它們。
