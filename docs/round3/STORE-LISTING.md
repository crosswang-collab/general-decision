## 台灣（zh-Hant-TW）

主要分類建議：**美食佳飲（Food & Drink）**；次要：生活風格（Lifestyle）。與 `public/manifest.webmanifest` 的 `categories` 一致。

### 名稱

```
報告班長｜決斷連
```

### 副標

```
選擇困難？班長下令，立刻出發
```

### 關鍵字

```
口令,今天吃什麼,午餐,晚餐,猶豫,附近美食,餐廳,宵夜,下午茶,決定,探店
```

設計理由：
- 主打「班長／口令／選擇困難／附近美食」，不搶「轉盤」「抽籤」（R2§4：台灣已有大量輕量轉盤，我們靠「真店＋記憶」差異化，不靠同一組詞跟它們比）。
- 「班長」「決斷連」「報告」已在名稱裡，不重複；「決定」「探店」是搜尋量導向的泛詞，保留。
- 沒有任何其他 App 名稱、沒有「Google」、沒有價格。
- 實算 bytes 由測試輸出；這組距離 100 bytes 還有餘裕，可加 1–2 個詞再跑測試。

### 宣傳文字

```
午餐吃什麼、晚餐去哪？別再想了，班長一句口令替你決定。派你去附近真實營業的店，盡量是沒去過的；你說不要再來的，班長記住了。每週日還有班長講評。
```

### 描述

```
選擇困難的你，需要一個不給你商量餘地的班長。

「報告班長・決斷連」不是轉盤，也不是抽籤。你按一顆鍵，班長用一句口令替你做決定：中午吃什麼、晚上去哪、現在去哪喝一杯、幾點該熄燈、那則訊息現在回不回。

【吃和歇，派你去真的店】
・依你的位置，從附近正在營業的店家裡，由程式選出一家，班長只負責下令。
・口令卡直接告訴你店名、步行幾分鐘、營業到幾點、價位，一點就開地圖，三秒內知道往哪走。
・預算自己選：在台灣用新台幣、在日本用日圓，自動換成對應的檔位；店家沒有公開價位時，班長會老實說「價位未知」，不亂編。
・同一個地點連按，不會一直派你去同一家。

【班長記得你】
・派過哪些店、你回報完成的、你說「今天不想吃這類」或「這家不要再來」的，班長都記在你的手機裡。
・首頁一鍵切換偏好：熟門熟路、均衡、全面偵察。
・口令卡會告訴你這家是沒去過的新據點，還是你第幾次回防；日記累積「新占領」與「回防」的數字。
・每週日，班長寫一份本週講評（莒光園地）：口令數、服從率、哪裡偷懶、下週對策。

【班長很兇，但只罵行為】
・三位班長，火力不同：菜鳥班長阿良、值星班長黑面、連士官長老郭，點名牌就能換。
・班長只拿你的拖延、猶豫開玩笑，不針對外貌、性別、族群、家庭，也沒有髒話。
・口令由 AI 即時撰寫，店是程式挑的。看到不妥的口令，口令卡上有「回報這道口令」。

【八張小事卡】
吃、去、歇、赴、幾點睡、這訊息現在回嗎、買不買、飛。大事不受理，班長只管小事。

【隱私，講白話】
・不用註冊、不用登入，沒有廣告，沒有第三方分析工具。
・日記與記憶只存在你的手機。
・伺服器每道口令只留幾行技術紀錄（模組、查詢類別或關鍵字、國家、火力、耗時），不含座標、店家代碼、店名、記憶。
・位置只在你叫班長查店時使用；不想給位置，手動報個車站或地標就行。
・第一次使用會先告訴你資料送去哪裡，你同意才開始。

報告班長，這個口令，你敢不執行嗎？
```

```

【食べる・休む は、実在のお店へ】
・現在地の近くで営業中のお店から、プログラムが一軒を選びます。班長は号令を出すだけ。

【班長はあなたを覚えています】
・行ったお店、行かなかったお店、「もうこの店はいい」は、すべてあなたのスマホの中だけに記録されます。

【班長は厳しいけれど、責めるのは行動だけ】
・見た目、性別、民族、家族をからかうことはありません。号令はAIが作成します。気になる号令は「この号令を報告」から連絡できます。

【プライバシー】
・登録もログインも不要。広告も、第三者の分析ツールもありません。
・位置情報はお店を探すときだけ使います。使いたくなければ、駅名やランドマークを手入力できます。
```
