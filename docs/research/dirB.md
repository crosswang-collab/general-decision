# 方向 B：借骨架，守身體

---

## 1. 一句話定位

**用美式卡通的骨架，穿一九九〇年代台灣兵的身體。**（23 字）

延伸一句給執行者：**借動詞（誇張、節奏、可讀性），不借名詞（臉、髮、體型、裝備）。**

---

## 2. 風格家族：家族 4 為骨架 × 家族 2 為表面

明確混合兩個，比重 7:3，分界線寫死。

**骨架 = 家族 4（Cartoon Network 90s 厚線）**，負責：頭部與五官的基本形構成、等寬粗描邊、外輪廓比內部線粗、極少色數、眉與嘴扛全部表情、四表情用零件替換。

選它的三個理由，按重要性：

1. **它是唯一在七個評估維度都沒有短板的家族**（研究表加權 79 分，第二名 68）。而這個案子的硬需求——96px 名牌可讀、1024 圖示撐得住、十二張一致、純 SVG 可做——剛好全部是它的強項。
2. **等寬描邊是 A 級向量。** 這代表 96px LOD 版可以「把所有線加粗到 3.5%」而不重畫任何東西。變寬線家族（家族 2、6、7）做不到這件事，這是整個生產流程能不能自動分級的分水嶺。
3. **它的調性是成人向黑色幽默，不是幼兒可愛。** Johnny Bravo、Dexter 的世界裡有「被權威壓著的荒謬」，這與軍教片同源。Duolingo 系（家族 9）的統一圓角會把三個成年班長變成三隻同款公仔，這是它唯一但致命的短板。

**表面 = 家族 2（UPA 中世紀現代主義扁平）**，只借三樣東西：

1. **色塊與線刻意錯位 2–3%**。這在技術上是「同一路徑複製一份、位移、改填色、置於線層之下」，純 A 級向量。而它在文化上直接等於**九〇年代台灣部隊印刷品的套色不準**——莒光日教材、油印公文、部隊月曆都長這樣。**一個技法同時解決「娛樂化的手感」與「年代感」，這是方向 B 最划算的一筆。**
2. **大幾何頭形帶來的剪影差異容量**（家族 2 在這項是 5 分，全表最高），但只用在帽子與肩線，不用在下顎（原因見第 3 節）。
3. **成人頭身比 1:4–1:6 的骨架感**，用來抵銷家族 4 的大頭化傾向，讓比例落在台灣兵而不是美國卡通兒童。

**明確排除**：rubber hose（家族 1，它的年代感是美國 1930，會與台灣 1990 互相消滅）、Pixar 立體（家族 8，無網格漸層、一致性退化成機率問題）、indie 手繪（家族 7）、超級英雄／G.I. Joe 系（軍國主義視覺語彙，零容忍）。

## 3. 角色造型規則

以 1024×1024 master 為單位。所有數字可直接發包。

### 3.1 全域

|---|---|---|
| 頭身比（bust 構圖下的等效） | **1:4.5**（頭高 620／全身推算 2790） | 家族 4 的 1:2 大頭在 38% 欄寬下臉會太小；1:4.5 是「卡通但成年男性」的下限 |
| 臉高（下顎到髮際） | **580**（佔畫布 56.6%） | 守住 §14 的 55–65% 契約，取偏下緣，為帽子留 130 |

| 眼距（兩眼中心） | **250** | 三人一致 |
| 外輪廓線寬 | **32**（3.1%） | 96px 上 3.0px，過門檻 |
| 內部結構線寬 | **20**（2.0%） | 眉、嘴、領、袋蓋 |
| 裝飾線寬下限 | **24** | 低於此值的元素在 96px LOD 版直接刪除，不縮小 |

### 3.2 頭形（這一節是方向 B 與純美式方向的分歧點）

家族 4 的標準作法是「每人分配一個基本形並推到極端」——圓、方、倒三角。**方向 B 拒絕把這三個形放在下顎上。**

理由來自文化轉譯研究：方下巴、下巴比顴骨寬、裂下巴，是西方臉的權威語法。三人用三個下顎形，等於做出一個穿草綠服的白人、一個穿草綠服的美國海陸、一個穿草綠服的老白人。這是「舒服的錯」——它會很好看，所以會被通過。

**三人共用同一條台灣臉下顎曲線：顴骨最寬（寬 500）、下巴窄而略圓（寬 300、圓角半徑 70）、鼻樑起點低而短、人中淺、不挖眼窩。** 三人之間只允許整體寬度 ±6%（阿良 −6%、老郭 +6%）。

**基本形的差異全部移到帽子、髮、肩三個載體**，每人必須有一個跨出頭部外輪廓 ≥ 48 單位的凸起或凹口：

| | 阿良 lv0 | 黑面 lv1 | 老郭 lv2 |
|---|---|---|---|
| 剪影關鍵字 | **右上斜尖** | **方平頂** | **兩側外翻＋頸部 V 口** |
| 船形帽 | 傾 **15°**（現行 7° 在 96px 等於 0.6px，等於零），帽尖上翹凸出 70 | 帽體最高最方，頂部平台 +60，前後角方切 | 帽簷壓低，帽體向後推 40 |
| 髮 | 帽後一撮呆毛凸起 70 | 三分頭，不露出輪廓 | 帽下白髮**向兩側外翻各 60** |
| 肩 | 窄梯形，肩寬＝頭寬 ×1.35，雙肩對稱 | 肩寬 ×1.55，**值星帶使右肩抬高 50，刻意不對稱** | 肩寬 ×1.45，哨繩在頸部形成深 60 的 V 形凹口 |
| 頸 | 頸寬＝頭寬 ×0.42（**頸必須比頭窄**，頸比頭寬就是 G.I. Joe） | ×0.45 | ×0.44 |

**必須先驗證的假設**：這三個剪影差異能不能過「全黑、48px、並排」測試，我不確定。它比「圓／方／倒梯」弱——那是這個方向為了守住台灣臉付出的第一筆代價。**建議在投入十二張之前，先只畫三個純黑剪影做這一關。過不了就必須加大帽子差異（而不是回頭動下顎）。**

### 3.3 眼睛

家族 4 的巨大眼是它 96px 可讀的一半來源，但研究點出的種族刻板風險是真的：**只有東亞角色是細線眼會落進「瞇瞇眼」檔案。**

規則：**三人眼型必須明顯不同，且每人至少一個 mood 是眼睛完全睜開。**

| | 眼構成 | 睜開的 mood |
|---|---|---|
| 阿良 | 正圓眼白 D140 ＋ 圓瞳 D56 ＋ 左上高光 D24 | idle、bark（他永遠是圓眼，這是他兇不起來的來源） |
| 黑面 | 橫向膠囊眼白（長 150 高 52）＋ 實心方瞳 44×44 | punish（圓瞪，眼白全出） |
| 老郭 | **老花眼鏡滑到鼻尖**：鏡框圓角矩形 150×100，框線寬 **24**，鏡片填 12% ink（不透明，否則 96px 消失）；鏡片後仍畫得出眼 | punish |

**老郭不用墨鏡。** 墨鏡＋方下巴＋哨子垂胸＝ R. Lee Ermey 的完整組合，在家族 4 的厚線下會被那個引力直接吸走。代價很誠實：**墨鏡是目前 96px 可讀性最強的配件（一大塊深色），拿掉會掉重量。** 補償是把重量還給帽子——**帽簷在眼睛上方投一道硬邊陰影色塊**（Tartakovsky 技法，純向量、一個填充路徑），色塊高 90、寬跨整臉。這塊陰影在 96px 上是 8.4px 的深色橫帶，比墨鏡更早被讀到，而且它是「壓低帽簷」這個台灣士官長的真實姿態，不是美國教官的配件。

哨子保留，但**哨繩穿過肩袢、哨子收進左胸袋**，不是教練式垂在胸前。

### 3.4 用色數與陰影

- **每個角色最多 6 個填充色 ＋ 1 個描邊色。** 明細：膚色、膚陰影、草綠、草綠陰影、白（名牌／內衣領）、一個識別色（金／紅）。
- **陰影只有一階，硬邊，不是漸層。** 光源固定左上 45°，全部十二張不變。
- **零漸層、零模糊、零 3D。** 立體感的唯一來源是硬邊陰影色塊與外輪廓加粗。
- **例外一個：色塊錯位。** 草綠服的填充色向右下位移 **18 單位**（1.75%）跨出線外，再用一層 6% ink 的網屏色補在缺口——這是印刷套色不準，不是漸層。它只做在制服上，不做在臉上（臉錯位會讀成重影）。

### 3.5 不可讓渡的裝備（任何簡化程度下都必須在）

排序即預算順序。**要砍細節，永遠先砍臉，絕不砍裝備。**

1. **帽徽＝虛構部隊徽**。十二道放射短芒＋圓框的節奏，明確不是國徽本體、**明確不是五角星**（現行 CHARACTER-BRIEF §0 寫的金色五角星是錯的，且在台灣是會被截圖轉發的錯）。芒長 ≥ 24。
2. **值星帶**：紅底＋細金邊，斜掛。**方向（左肩或右肩）必須先找一張確實的參考照定死，然後逐張人工驗收**——生成模型每張都會隨機翻面。
3. **草綠服結構**：純色（**任何迷彩即退件**）、開領、兩個胸袋蓋、寬鬆。燙線線寬不足 24，**在 96px 版刪除、在 512/1024 版保留**。
4. **右胸白色硬質名牌＋繁體中文姓名**。牌體 180×64，必須在 96px 仍讀得出「白牌子上有中文」（字讀不出來沒關係，材質讀感要在）。
5. **三分頭（非 high-and-tight）＋帽子曬痕**。曬痕做法：額頭一條淺膚色硬邊色塊，高 80，寬跨整額——**硬邊，純向量，成本近乎為零，識別力極高**。
6. **內衣白領從領口露出一截**（高 30）。極在地、極便宜。
7. **三人士官階級章可辨不同**（確切形制需查證）。

### 3.6 第五個表情：`soft`

四個滿幅度表情撐不起「刀子嘴豆腐心」。家族 4 的表演訓練是「每格幅度拉滿」，一旦照做，角色會從班長變成霸凌者。

新增 `soft`：**罰則倒數結束後的 200ms 切一幀**——眼神別開（瞳孔移至眼白外側 70%）、嘴平（一條 h20）、3/4 側向。這一張圖是整個產品「情義」的唯一載體，**也是這個方向與純娛樂化方向最大的差別**。程式代價見第 9 節。

## 4. 三段火力：整個 app 的氣壓

換頭像只是入口。方向 B 把 level 升級成一組**四個 CSS 變數**（`design/build.mjs:16/23/30` 已經有這個概念，但 `src/styles.css` 目前不存在，要正式建立）：

```
:root[data-lv="0"] { --cmd-bg; --cmd-line; --w-head; --overshoot; --stripe }
```

| | lv0 阿良 | lv1 黑面 | lv2 老郭 |
|---|---|---|---|
| 命令卡底 `--cmd-bg` | `#6B7D45`（最亮的軍綠） | `#5A6E35` | `#2F3A1E`（近墨橄欖） |
| 卡片邊框 `--cmd-line` | 2px `--line` | 3px `--ink` | 3px `--gold` |
| 大字字重 `--w-head` | 700 | 800 | 900 |
| 進場過衝 `--overshoot` | `cubic-bezier(.25,1.2,.5,1)`（1.02） | `(.34,1.56,.64,1)`（1.06） | `(.3,1.8,.6,1)`（1.10，且多一次可見回彈） |
| tag 斜紋 `--stripe` | 無 | 一道紅 | 紅＋金雙道 |
| 按鈕厚度 | `0 3px 0` | `0 4px 0` | `0 6px 0` |
| 罰則倒數節拍 | 1000ms | 600ms | 500ms（已存在，現在綁上視覺） |
| 背景 | 卡其不變 | 卡其不變 | **卡其不變**（見下） |

**背景刻意不隨 level 變。** 理由：背景是所有畫面的最大面積，隨 level 換底色會讓 app 看起來像三個不同產品，且 `tests/e2e/system.spec.ts:8/15` 硬驗兩個卡其值，改了就紅燈。火力的壓迫感靠**卡片變深、邊框變重、字變粗、動態變狠**，不靠換底。這也符合文化研究的那條界線：壓迫感來自時鐘與份量，不來自把使用者壓在下面。

**換班長的那一刻要有演出**：點頭像 → 整個 `:root` 的四個變數在 260ms 內過渡 → 命令卡底色滑到新值、邊框加粗、按鈕厚度長高。使用者會看到「氣壓變了」，而不只是「換了一張臉」。這是最便宜、最有效的娛樂化投資（一個 CSS transition）。

## 5. 調色盤

| Token | 現值 | 方向 B | 處置 | 理由 |
|---|---|---|---|---|
| `--khaki` | `#E3DFD0` | **`#E3DFD0`** | **完全保留** | 唯一中性底；三個彩色都要提飽和，更需要一個安靜的底；且 e2e 硬驗此值（light `rgb(227,223,208)`／dark `rgb(23,24,19)`），改了要動測試 |
| `--ink` | `#1B1D1A` | **`#1B1D1A`** | 保留 | 同時是描邊色，統一 UI 與角色 |
| `--olive` | `#4A5733` | **`#5A6E35`** | **調整**（S 27%→35%、L 27%→32%） | 現值是真實 olive drab，在厚黑描邊旁會糊；提一階拿到色彩活力，仍在軍綠區間，不往螢光綠也不往藍綠走 |
| `--olive2` | `#39452A` | **`#414F26`** | 調整（同步重算，否則明暗關係斷） | |
| `--signal` | `#B3261E` | **`#B3261E`** | **保留為語意色** | 它是值星帶與哨繩的顏色（角色耦合最深），也是系統唯一語意色，不該隨風格搖擺 |
| `--alarm` | 無 | **`#D93A22`** | **新增**，只用在 stand 罰則卡底 | 把「系統錯誤紅」翻成「警報紅」。**對比誠實話**：與白字約 3.9:1，未達 4.5:1；只用在 ≥24px、weight 800 的大數字與大字（3:1 門檻）上，小字一律 ink。高對比模式下退回 `--signal` |
| `--gold` | 只存在於 `design/build.mjs` | **`#EFC03A`** | **正式升為 src token** | 現行 `#D4AF37` 是做舊的古典金，在卡通環境裡發灰；提亮後撐得起儀式感 |
| `--gold-deep` | `#7A6314` | **`#8A6A12`** | 保留結構、微調 | 金的兩段處理已是現成結構 |
| `--paper` | 只存在於 `design/build.mjs` | **`#F2EEE0`** | 新增 | 步驟白卡、日記卡用，與卡其底分層 |
| `--tan`（曬痕） | 無 | **`#F3D9BC`** | 新增 | 角色 SVG 用 |

**對 C1「可調不可換族」的立場**：不推翻。四色全部保留族群，兩個提飽和（olive、gold）、兩個保留（khaki、signal）、新增兩個功能色（alarm、paper）。這是「逐色分級」而不是「整組一致」——理由是研究指出的不對稱性：金的風險最低、草綠最高，強行整組同幅處理會在草綠上出事。

**深色模式**：十個 token 全部要有 dark 對應（現行已有機制）。提飽和後最危險的是 `--alarm` 在暗底發光，dark 版降到 `#B8341F`。

**寫死值的同步清單**（改版最容易漏）：`index.html:7` 的 `theme-color`、`public/manifest.webmanifest:9-10`、`design/build.mjs:10-11` 的手抄調色盤、`src/avatar.tsx` 的十幾個字面色。**avatar SVG 的顏色目前完全不走 CSS 變數，深色模式下頭像不變色**——方向 B 建議把 avatarSvg() 改成接受一個 palette 物件，但這會動到 `design/build.mjs:5` 的相依，是一筆要先算清楚的帳。

## 6. UI 怎麼跟著變

### 6.1 home（首頁）

- `.officer .av` 從 5.75rem 方框 → **7rem**，`border-radius:10px → 20px`，加 `box-shadow:0 4px 0 var(--olive2)`（硬陰影、blur 0）。頭像變成畫面第一個被看到的東西。
- `.bubble` 對話框加**尖角指向頭像**（一個三角形 ::before），厚度 2px ink 邊框。現在它才是「他在說話」，不是「一段文字」。
- 4 大磁貼 `.tile`：radius 8px → **18px**，border 1px `--line` → **2px `--ink`**，`min-height 5.5rem → 6.5rem`，`.tile b` 的數字改 `--gold` ＋ 2px ink 描邊。
- **idle 動態**：頭像每 5±0.5 秒眨眼 120ms（兩個群組的 visibility 切換，零成本）。`prefers-reduced-motion` 下關閉。
- 底部加一行 90 年代印刷質感：卡其底疊一層 3% ink 的細點網屏（CSS `background-image` 的 repeating gradient，**不進角色 SVG**，避免 96px 摩爾紋）。

### 6.2 cmd（命令卡，4:5）

- 兩欄仍是 grid 兄弟節點、角色 `align-self:end`、不絕對定位——**規則 2 與 `tests/unit/avatar.test.tsx:63-70` 的 `['tag','txt','face']` 三子節點契約完全遵守**。
- **但 `1fr 38%` 建議放寬到 `1fr 42%`。** 理由：1:4.5 的頭身比在 38% 欄裡臉只剩約 105px @1290 寬，名牌中文與曬痕全部消失。零測試綁定（全專案唯一的 gridTemplateColumns 斷言只驗週報的單欄），**但它是 §9 規則 2 的成文數字，需要 Cross 裁決。** 這是方向 B 唯一觸碰產品層版面規則的地方，我把它標成裁決項而不是自己改掉。
- `.cap` 大字：現行五向 `#000` text-shadow 保留（它已經是娛樂化的字），但字級跳躍從 `1.4/1.19/1.6` 改成 `1.33/1.5/2.0`，讓 `.num` 進到 3rem 以上。
- 卡片 radius 10px → 18px，加 `--cmd-line` 邊框與 `0 5px 0` 硬陰影。
- **步驟白卡完全不動娛樂化**（規則 4 是產品層）：`--paper` 底、`▸` 前綴、無梗、字重 600、radius 8px 保持。**它的「無聊」現在變成一個刻意的對比——毒在上面那張卡，情報在下面這張。**

### 6.3 stand（罰則倒數，4:5 紅卡）

這是整個方向道德位置的測試點。

- 卡底 `--alarm`，大數字 4.5rem／weight 900／3px ink 描邊。
- **倒數每一拍：數字 `scale 1.0 → 1.18 → 1.0`（140ms）＋ 卡片邊框閃一下。** 壓迫感來自時鐘。
- **班長的姿態是抱胸、別過頭、等。** 不放大、不貼臉、不破框、不指地板、不出現任何體罰器具或暗示。攻擊性全部由 `meme.top` 的文字承擔。
- 倒數結束 → **切 `soft` 一幀 200ms** → 回首頁。這 200ms 是整個產品裡唯一一個「他其實沒那麼兇」的訊號。

## 7. 主視覺

**三格等距並列，同槽位疊影，明度階梯。**

- 畫布 1600×1000（可裁 1200×630 OG、1080×1350 社群）。
- 三格等寬，**無間隙、共用一條底線**。眼線與肩線三格完全重合（這是槽位契約帶來的免費構圖優勢）。
- **背景明度階梯，由左到右變暗**：左 `#E3DFD0` 卡其 → 中 `#5A6E35` 草綠 → 右 `#1B1D1A` 墨。**火力上升，一個字都不用寫。**
- **表情用 idle ／ bark ／ punish**，不是三個 idle。讀成「同一個動作被三種人執行」。
- **佔滿度遞增**：三人比例完全一致（不放大），阿良留白多、老郭帽頂裁切到畫框外。壓迫感靠留白，不靠尺寸。
- **紅色全圖只出現兩次**：中格黑面的值星帶、右格老郭的哨繩。兩點連成一條斜向動線，把三格串起來並指向右。
- **底部一條金色刻度線，三個 tick，第 2 個高亮**（對應預設 level 1）。這條刻度是把「合照」翻譯成「選擇器」的關鍵零件——沒有它，這張圖會被讀成三個角色的故事。
- **全圖疊九〇年代印刷處理**：色塊錯位 1.75%、3% 網點、金色略髒、邊緣輕微褪色。**這層處理是方向 B 與純美式方向在 KV 上最明顯的分野**，也是「莊嚴 → 懷舊」的解毒劑（飽和草綠＋銳利高對比金＝極權海報配方；舊與土會殺死莊嚴）。
- **不放**：仰角、頭後放射光束（金色短芒只准兩側成對、≤4 道、絕不成圓）、五角星、多人列隊、老鷹月桂旗幟、槍、手機外框、App Store 徽章。

備案（一人三面／三層疊影）語意更準但小尺寸必糊，**只能用在大 KV，不可用於截圖或社群縮圖**。

## 8. 代價（這一節請當成提案的主體）

### 8.1 它犧牲了什麼

**犧牲純度。** 這是一個中間路線，它既不是最好笑的美式卡通，也不是最正的台味懷舊。問「像哪部作品」，答案是「沒有」。這在募資、找繪師、對外解釋時是實質成本——你無法指著一張參考圖說「就這個」。純方向（全美式或全台味）可以，方向 B 不行。

**犧牲「外國人也覺得好看」的一半。** 名牌繁體中文、值星帶、燙線、曬痕、船形帽對外國人是**無意義的噪點**——不是零收益，是**負收益**，因為它們增加畫面複雜度卻不傳遞任何訊息。這個方向能讓外國人覺得好看的部分，只有骨架（厚線、剪影、色塊）與配色，而那部分純美式方向做得更好、更省。**「一眼認出」與「國際好看」在這個方向裡不是相加的，是互相收稅的。** 我不認為兩者可以同時最大化，方向 B 的實際位置是「台灣 9 分／國際 6.5 分」，不是「9 分／9 分」。

**犧牲工時，而且是乘法不是加法。** 兩套驗收表（美式可讀性：黑剪影、灰階、LOD、疊圖；台味真實度：哪一國的兵、去制服、遮字、惡意截圖）互相拉扯。每次改動要兩邊都過。加粗線條有利 96px 但吃掉燙線；加曬痕有利在地但多一個色。**這個方向沒有「單純變好」的改動，每一筆都是交換。**

**犧牲現有資產。** `src/avatar.tsx` 的十二組參數要重寫，`tests/unit/avatar.test.tsx:39-44` 的 `rotate(-7 60 36)` 必紅（帽子 7°→15°）。墨鏡要拆掉——那是目前 96px 上最有效的一個元素。

**犧牲美式卡通一半的價值。** 美式卡通的靈魂是**時間**：squash & stretch、anticipation、smear、take。而現行資產介面是**每個 mood 一張靜態 webp，沒有序列、沒有多幀**。方向 B 在這個介面下只拿得到造型，拿不到節奏。要拿到節奏必須把角色改成 inline SVG 群組切換（可行，見第 9 節），但那等於放棄 raster 交件路線。**這件事沒有中間解，必須先選。**

### 8.2 什麼情況下它會失敗

**失敗模式一：四不像（機率最高）。** 誇張不夠大到好笑，在地細節又不夠密到有年代感。中間路線的標準死法。**早期偵測訊號**：如果第一張定稿看起來「乾淨、專業、還行」，它已經失敗了——這個方向對的時候應該是「有點土、有點怪、但很像我認識的那個人」。

**失敗模式二：舒服的錯。** 因為骨架讓給美式，繪師或生成模型會不自覺把臉也美式化——下巴變寬、鼻樑變高、眼窩挖深、髮型滑成 high-and-tight、制服變貼身。**而且它們會畫得很好看，所以會被通過。** 這個方向比純台味方向更依賴逐張人工驗收，因為它主動把一半的方向盤交給了一套會自己往美國開的語彙。

**失敗模式三：為了 96px 砍掉在地細節。** 名牌中文、燙線、曬痕、內衣領全部低於 24 單位或接近門檻。只要驗收時「為了清楚」把它們砍掉，這個方向就**只剩美式骨架，完全沒有台灣**——而那時你會有三個很好看的美國卡通兵，且看起來完全沒問題。**防線：LOD 規則必須寫成「96px 版可刪，512/1024 版不可刪」，而不是「不清楚就刪」。**

**失敗模式四：剪影測試過不了。** 第 3.2 節那個「不動下顎、只動帽髮肩」的決定，是為了守台灣臉付出的代價，而我**不確定它能過 48px 黑剪影測試**。如果過不了，只有兩條路：加大帽子差異（做得下去但會變成「三頂不同的帽子」而不是「三個人」），或回頭動下顎（那就退回純美式，這個方向的前提消失）。**這是唯一一個會讓整個方向作廢的假設，必須第一個驗證，成本只有三個純黑剪影。**

### 8.3 對文化轉譯研究裡哪些風險特別暴露

| 風險 | 暴露程度 | 為什麼方向 B 特別暴露 |
|---|---|---|
| **drill sergeant 引力**（墨鏡＋方下巴＋哨子＝ R. Lee Ermey） | **最高** | 家族 4 的厚線正是美式 drill sergeant caricature 最常見的畫法。方向 B 主動拆掉墨鏡與方下顎來抵抗，但這是逆著風格家族的重力走——每一次「這樣比較好看」的微調都會把它推回去 |
| **「舒服的錯」** | **最高** | 見失敗模式二。純台味方向沒有這個風險，因為它一開始就不借美式語彙 |
| **大表情 = 只剩兇，情義消失** | **高** | 家族 4 的訓練是每格幅度拉滿。方向 B 靠第五 mood `soft` 對抗，但那是一張沒有畫面在用的圖（要加程式），也是最容易在排程壓力下被砍掉的一張 |
| **台灣使用者的卡通識讀是日系的** | **中高** | 方向 B 同時保留日式漫符（阿良的汗滴 `#5DADE2`）與美式骨架，等於混三種語彙。汗滴對台灣人的可讀性確實高於任何美式等效物，所以留它是對的——但它讓「風格一致性」這題永遠拿不到滿分 |
| **大頭比例 vs 38% 欄寬的物理衝突** | **中** | 方向 B 把頭身比壓到 1:4.5 來緩解，但仍需要把欄寬推到 42%。這是研究點名的「唯一一條產品層規則可能被新風格物理性挑戰」的地方，方向 B 確實踩到了 |
| **旭日旗誤讀** | **低但不可忽視** | praise 的金色放射短芒必須硬規：只在兩側、成對、≤4 道、絕不成圓、絕不紅白。一旦繪師「美式化」成頭後全圓放射，就是旭日旗 |
| **值星帶方向隨機翻面** | **中** | 這是流程風險不是風格風險，但方向 B 若走生成路線會每張翻；走向量路線則是零風險（同一條路徑） |
| **五角星** | **已在方案內解決** | 改虛構部隊徽，這題消失 |

## 9. 生產可行性

### 9.1 純 SVG 做得出來嗎

**做得出來，A 級。** 逐項盤點：

| 元素 | 級別 | 說明 |
|---|---|---|
| 頭形、帽、肩、眼、眉、嘴 | **A** | 正圓、圓角矩形、梯形、膠囊、等寬描邊。全部 SVG 原語 |
| 粗外輪廓比內部線粗 | **A** | 同一路徑先粗描邊墊底、再填色疊上，兩層 |
| 硬邊陰影（帽簷投影、膚陰影） | **A** | 填充路徑，Tartakovsky 技法 |
| **色塊錯位（印刷套色不準）** | **A** | 同路徑複製＋位移＋改填色＋置於線層下。**這是方向 B 的年代感主要載體，而它恰好是純向量最擅長的** |
| 曬痕 | **A** | 硬邊淺膚色塊，不是漸層 |
| 燙線、白髮線、法令紋 | **A**，但 <24 單位 | 96px LOD 版刪除，512/1024 保留 |
| 名牌中文 | **A** | `<text>` 或外框化路徑 |
| **紙纖維、網點、膠捲顆粒** | **C** | **不進角色 SVG**。只做在 UI 背景層（CSS repeating-gradient）與 KV 的後製層。96px 下網點必摩爾紋 |
| 四表情切換 | **A** | 群組替換（Hanna-Barbera 的 mouth chart 邏輯）。總資產＝3 頭 ＋ 3 身 ＋ 5 組眉 ＋ 5 組嘴 ＋ 3 組配件 ＝ **19 件零件組出 15 張（3×5）** |

**不需要繪師算圖，也不建議走 ChatGPT 生 12 張的路線。** 現行 `docs/CHARACTER-BRIEF.md` §3 那條流程與這整套分析互斥：你會拿到 15 張互不相關的點陣圖，每張的線寬、眼線、配件都重新擲骰子，而 §4 的檢查表全都是在人工彌補這個結構缺陷。

### 9.2 建議流程（三步）

1. **人工定稿 1 張**：阿良 idle，找**台灣繪師**畫（不是生成）。這一張是「風格定稿」不是「交付資產」。同時附上真實的草綠服、船形帽、值星帶、名牌**參考照片**，不要讓模型或繪師發明裝備。
2. **轉成向量 master**：依 3.1 的格線重建為純路徑，所有形狀對齊到表中數字。
3. **其餘 14 張由零件重組**：換頭部配件組（3）× 眉組（5）× 嘴組（5）。每一張的眼線、肩線、線寬**必然**一致——`§4 驗收表`的「三人眼線肩線一致」「配件沒多沒少」從「每次人工檢查」變成「結構上不可能失敗」。

**匯出兩個 LOD**：1024 完整版（App 圖示、KV、分享卡）、96 簡化版（名牌位、tab icon；刪除 <24 的線、外輪廓加粗到 3.5%、關閉色塊錯位與網點）。

## 先驗證再投入的三件事（依序，總成本半天）

1. **三個純黑剪影，48px 並排。** 過不了，第 3.2 節的前提作廢，整個方向要重談。
2. **五個當過兵的人，看 96px 縮圖、不給任何說明、2 秒內答「這是哪一國、哪個年代的兵？」** 通過條件 5/5 答台灣、≥3/5 答得出 90 年代。這是唯一能抓到「看起來很好但其實是美國兵」的方法。
3. **SVG vs raster 的架構選擇。** 決定了這個方向能拿到造型還是拿到造型＋節奏。
